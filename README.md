# House Price Prediction Using Linear Regression

## Project Overview

This project uses Linear Regression, a supervised machine learning algorithm, to predict house prices based on input features from the dataset.

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Load and explore the dataset.
2. Prepare the input features and target variable.
3. Split the data into training and testing sets.
4. Train the Linear Regression model.
5. Predict house prices using the trained model.
6. Evaluate model performance.

## Algorithm

**Linear Regression** is a supervised machine learning algorithm used to predict continuous numerical values by identifying relationships between input features and the target variable.

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/pranavfatkar26/House-Prediction.git
```

Navigate to the project directory:

```bash
cd House-Prediction
```

Install the required libraries:

```bash
pip install numpy pandas scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `Project of Linear Reg model.ipynb` and run the cells.
